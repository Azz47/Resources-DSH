# 验收清单（通用版 · 每册收工前逐条过）

> 用法：勾选 = 「检查对象 × 判定标准 × 取证结果」三者齐全。任何一条豁免，必须在该行末尾写明**豁免页集合 + 理由**；口头豁免不算。
> 本清单是通用版；单册特化版（带基线数字）见 `decks\单元思考与行动-参赛版\` 对应的 `corpus-teardown-acceptance.md`。
> 建立 2026-10-18；阈值来源：`参赛要求.md` H1–H7、`kit3.py` 常量、v2 pptx 实测（45 页 / 902 个 run）。

## A 几何（画布与净空）

- [ ] **A1 画布**：960 × 540 pt（pptx 12192000 × 6858000 EMU）。判据：`slide_width/12700 = 960`。
- [ ] **A2 右侧净空（硬约束）**：所有**承载信息**的元素右边界 ≤ **640 pt**；640–960 只允许竖排单元名、页码、短横、低对比装饰（v2 实测：线 648、短横 647–657、竖排名 662–684、页码 662–722，全在 640 右侧，放行）。判据：跨 640 的正文文字数 = 0；整块在右侧带的元素计入装饰。
- [ ] **A3 页眉线**：通栏线位于 `y = 128`（浅底页）；深底页强调线 `y = 156`。判据：抽查 5 页 yaml/pptx 坐标。
- [ ] **A4 正文区**：`y ∈ [142, 462]`；底部不得越过 496（540 − 44 安全区）。判据：元素底边 ≤ 496。
- [ ] **A5 左边界**：内容左边界统一 48（卡片内文字 48+16+3）。判据：同层级左边界全册一致。
- [ ] **A6 无重叠**：文字框与背景图/装饰块不重叠；同一区域不出现两层文字。判据：`ppt_shot` 抽 6 页人眼看 + yaml 坐标相交检测。

## B 字号与对比度

- [ ] **B1 字号阶梯**：正文 16、卡片标题 18、页面标题 28（深底 30）、注释/标签 14、右侧带与 KPI 标签 13、KPI 数字 38。判据：**阶梯外的字号 = 0**（展示级字号如封面 44 / 大编号 104 需在册记录里声明）。
- [ ] **B2 字号下限**：任何文字 ≥ **14pt**（若坚持 12pt，则必须改掉 `deck.yaml` 的 `minFontSize` 并在册记录里说明理由）。判据：pptx 实测最小 run 字号。
- [ ] **B3 对比度（正文）**：正文/注释对底色 ≥ **4.5:1**；≥18pt 粗体或 ≥24pt 大字 ≥ **3:1**。实测基线（纸面 `#F6F3EC`）：

  | 色 | 比值 | 结论 |
  |---|---|---|
  | `#17242E` INK | 14.27:1 | ✅ |
  | `#3B4B57` INK2/MUTED | 8.13:1 | ✅ |
  | `#1C6B60` TEAL | 5.71:1 | ✅ |
  | `#2E6E8F` STEEL | 5.06:1 | ✅ |
  | `#B4552F` RUST | **4.43:1** | ❌ 正文禁用；改 `#9E4525`（5.69:1） |
  | `#A8812F` GOLD | **3.24:1** | ⚠️ 仅装饰/大字；正文禁用 |
  | `#EAF0F4` / `#B9C9D4` on `#0E2A47` | 12.68:1 / 8.58:1 | ✅ |

- [ ] **B4 色不过载**：一页强调色 ≤ 2 种（环节色 + 金/锈其二）；全册强调色 = 5 色系（NAVY/STEEL/RUST/TEAL/GOLD）。
- [ ] **B5 字号与粗细匹配**：14pt 不加粗（除标签）；粗体只给标题、KPI、标签。
- [ ] **B6 行高**：标题 1.25、卡片标题 1.35、正文 1.55、横条 1.5。判据：抽查 yaml `lineHeight`。

## C 讲稿（备注）

- [ ] **C1 覆盖率**：备注页数 = 幻灯片页数（v2 实测 45/45；v1 46/46）。判据：`sum(1 for s in slides if notes非空)`。
- [ ] **C2 时长**：约 **1 页/分钟**；总页数 ≈ 课时分钟数（45 页 ≈ 45 分钟）。
- [ ] **C3 一页一意**：每页讲稿开头一句点题，结尾一句过渡到下一页。判据：抽 6 页读备注，能找到「点题句 + 过渡句」。
- [ ] **C4 不念页面**：讲稿不逐字复述页面文字，补充例子/追问/易错点。

## D 转场与动效

- [ ] **D1 每页有转场**：`with_transition = 总页数`（v1 基线 46/46）。
- [ ] **D2 类型统一**：主讲用 `morph`（PPT 内）或淡入（导出件）；`morph-slow` 只给封面/环节页/结尾（v1：第 1/6/19/30/46 页）。
- [ ] **D3 不炫技**：禁止逐字飞入、旋转、弹跳；单页动效时长 700–1200 ms。
- [ ] **D4 深底页克制**：深底环节页不做元素逐条进场（投影下显脏）。

## E 内容结构

- [ ] **E1 依据页**：第 3–4 页内存在「课标/素养/价值」三栏页，且引用课标原文（含版本年）。
- [ ] **E2 节末整合**：每个教学环节结束后有一页【重点整合】/【本课小结】，条数 = 该环节要点数。
- [ ] **E3 答案分页**：练习页只给题，答案与解析单独一页；评分要点写可执行口径（如「每小题 2 分，多选、错选不得分」）。
- [ ] **E4 图证**：每张图对应一个论断，图下 13pt 注「来源 + 时间」；装饰图不计入。
- [ ] **E5 编号层级**：`一、` → `1.` → `（1）` → `①`，同页 ≤ 2 级；单条段落不编号。
- [ ] **E6 数字有账**：页面出现的每个事实性数字，都能在 `number-bank.md` 查到「口径 / 出处 / 截至」；`待核` 数量 = 0 才可进参赛件。

## F 交付物

- [ ] **F1 导出完整**：zip 无坏块、slides 数正确、xml_errors = 0。
- [ ] **F2 材料包**：课件 + 教学设计 + 说课稿/PPT + 导学案 + 作业 + 反思（缺哪项要明说，不得默认齐全）。
- [ ] **F3 命名规范**：`年级册别_课题_材料类型_姓名`；成品与工程分离（工程目录只放源文件）。

## H 判定与豁免

- **判定**：A/B/C/D/E/F 六组全过 = 可交付；任一条未过 = 不签，除非写明豁免。
- **豁免格式**：`豁免：p01, p06, p15, p23, p44（封面/深底环节页/致谢不设页眉素养条）`——必须**列页**且给理由。
- **不许的三种过法**：口头「差不多了」；改判据迁就产物；把未验证项从清单里删掉。
