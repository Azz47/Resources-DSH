# 数字库（number bank）

> 一句话：**课件里的每个数字，都要能回答「口径、出处、截至」三问**；答不上来就换成定性表述或删掉。
> 建立 2026-10-18。首轮盘点对象：`decks\进入新时代-参赛版-v2`（45 页，实测扫描 48 个 `pages\*.yaml` 的 `content.text`）。

## 0 规则（四条，硬）

1. **一个数字一行**，四要素齐全：数字 / 口径（统计范围 + 指标定义）/ 出处（媒体 + 文章 + 日期，能到链接就到链接）/ 截至日期。
2. **跨页只允许同一口径**：同一个数字出现在两页，必须引用同一行记录；口径不同的两个数字**不许写成「A 提升到 B」**。
3. **正文不写裸数字**：数字后面必须跟出处行（`src_note`，13pt）或口头交代的同一来源；页面上没地方写就降级为定性表述。
4. **没核实的不算出彩**：`待核` 状态的数字可以留在工程里练版式，但**进参赛件前必须转 `已核`**，否则替换或删除。

## 3 复核命令（可复跑）

```powershell
$py='C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe'
$deck='D:\Resources\DSH\decks\进入新时代-参赛版-v2'

# 列出所有含数字的文字块（含所在页）；--orphans 顺带报告不在 deck.yaml 的孤页
& $py 'D:\Resources\DSH\_specs\_scan_numbers.py' $deck --orphans

# 逐页数「来源注」条数：0 的那一页就是缺出处
Get-ChildItem "$deck\pages\*.yaml" |
  ForEach-Object { "{0}: {1}" -f $_.Name, (Select-String -Path $_ -Pattern '"elementId": "src_note"').Count } |
  Where-Object { $_ -match ': 0$' }
```
