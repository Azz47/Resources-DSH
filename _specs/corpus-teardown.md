## 1. 骨架只有两类，不是一类

**A 型 · 文字阐述型（政治 / 道法主流，样本 1/2/3/5）**
- 图/页比 ≈ 0.1（15 页里只有封面图 + 1~2 个图标）
- 每页 150–400 字，靠 **编号 + 标签 + 加粗关键词** 承载信息
- 表格用于「对比」（政策对比、制度对比、列强矛盾）
- 本质：**讲义投影**，讲得深、写得全

**B 型 · 图文并证型（历史，样本 6）**
- 图/页比 ≈ 0.8，每页必有一张「史料照片 / 地图 / 漫画」当证据
- 版式固定：**左图右文** 或 **上图下文**，图占 40–55%
- 每张图配 8–20 字小字注（时间 + 事件），不写长 caption
- 本质：**图证链**，用图说话、用字收口

> 对我们（道法）的可迁移结论：**A 型的标签体系 + B 型的图证手法**，两者都缺一不可。v2 现在只有 B 型的皮（前 12 页有图），没有 A 型的骨（后半册 30 页纯文字且无标签体系）。

## 2. 专业感来自「三件套」，且每页都有

| 件 | 位置 | 内容 | 作用 |
|---|---|---|---|
| ① 页眉三要素 | 页顶 22–30pt 高的细条 | 左：学科标识（「历史」「政治」色块）｜中：教材/单元（「必修 中外历史纲要（下）」）｜**右：★ 核心素养** | 评委第一眼看到「素养导向」 |
| ② 页脚 | 底部居中/右 | 「[第 N 页]」 | 翻页定位、显得完整 |
| ③ 标签系统 | 标题前 / 段首 | 【】预制件 | 一册同一套，形成"教材感" |

**【】预制件清单（样本里高频出现，按频次）**
`【课标要求】` `【学科素养】` `【学习目标】` `【核心价值】` `【时空坐标】` `【知识归纳】` `【知识点 N】` `【思维点拨】` `【探究与分享】` `【史料】` `【提示】` `【解析】` `【答案】` `【重点整合】` `【总结】` `【真题演练】`

> 关键：**同一册里标签的字号、颜色、位置完全一致**。这不是装饰，是「认知地图」——学生/评委知道看见【提示】就知道下面是要动脑的。

## 3. 一屏究竟怎么排（样本页型占比）

| 页型 | 占比 | 结构 |
|---|---|---|
| ① 标签 + 段落 | ≈40% | 页眉 → 【知识点 N 标题】 → 1./2./3. 段落（关键词加粗+下划线） |
| ② 表格化对比 | ≈15% | 页眉 → 标题 → 2–5 列对比表（无竖线、浅底表头） |
| ③ 图文并证 | ≈20% | 页眉 → 左图（史料/地图）+ 右文 或 上三图 + 下文 |
| ④ 问题→答案分页 | ≈10% | 问题页只放材料+问句；**答案单独一页**，标题就叫【答案】/【解析】 |
| ⑤ 过渡空白页 | ≈5% | 一行字 + 一个图标 + 大片空白（如「自主学习释疑解惑」「重难探究｜素养初培」） |
| ⑥ 目录/结构页 | ≈5% | 「知识归纳｜识记理解」，左侧窄标签 + 右侧条目 |
| ⑦ 封面 / 结束页 | ≈5% | 三级标题：单元 → 课 → 框 |

**一屏的黄金配比（A 型实测）**：标题 1 行（≤24 字）＋ 正文 3–5 块 ＋ 每块 ≤3 行。「一块一意，块块带标签」。

---

## 4. 编号即层级

样本全部用 **`一、` → `1.` → `（1）` → `①`** 四级编号表达层级，而不是靠字号/颜色区分。
- 好处：投影缩小后层级仍然清楚；讲课时可以直接说「看第 2 点第（3）小点」。
- v2 现状：靠卡片和位置区分，**没有编号**——评委无法"点名"，学生无法"回指"。

---

## 5. 图片选取的三条硬规矩

1. **图必作证，不作装饰**：B 型每张图都对应一个论断（萨拉热窝事件→导火线、凡尔登→伤亡规模）。
2. **图必带来源**：图下 8–14pt 小字标「图源 + 时间」，样本里 100% 有。
3. **同类图统一处理**：同一页的 3 张图同高、同宽、同边框、同注位（样本 6 的「三国协约/同盟」三联图）。

> v2 现状：图有来源，但**图的论证功能弱**——多数是"配图"不是"证据"；且后半册无图。

## 6. 课程设计思路（引导内容怎么串）

样本的教学逻辑高度一致，是**四段式**：

```
依据（课标/素养/价值 三栏页）
  → 知识（【知识点 N】逐条展开，每条配【思维点拨】）
    → 探究（材料 + 问题 + 【提示】三级递进）
      → 整合（【重点整合】把散点收成 3–5 条）
        → 演练（【真题演练】+【解析】/【答案】分页）
```

- **「依据页」是第一梯队必备**：样本 1/3/5 的第 3 页都是三栏（课程内容 / 学科素养 / 核心价值），一页把"为什么教这个"说清。
- **探究三级**：材料给事实 → 问题给方向 →【提示】给脚手架，**不给答案**（答案另页）。
- **整合页**：每节结束必有一页把本节 3–5 条收口，标题统一【重点整合】/【本课小结】。

> v2 现状：有探究（p19/p29 思辨）、有小结（p34/p35），但**缺「依据页」**，也**缺"节末整合"**——三个环节结束后没有各自收口。

## 9. 样本局限（必须如实说）

- 这些是 **1ppt 公开课的「讲授型课件」**，不是「40 分钟录像课参赛课件」——后者更强调学生活动与生成，A 型的"满页文字"照搬会失分。
- 可读页只有 8–15 页/册（1ppt 免费预览给的是前几页，很多册只有封面），**看不到完整册的节奏**。
- 750×422 分辨率，字号只能反推（约 24/20/16/14），不能当精确值。
- 结论应作「做法参考」，最终仍以当届评分细则 + 我们的课堂设计为准。
