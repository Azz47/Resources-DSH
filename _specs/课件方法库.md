### 册 001 · 第二单元 进入新时代 · 单元思考与行动（九上道法）· v2

| 项 | 值 |
|---|---|
| 日期 | 2026-10-17 建稿，2026-10-18 复盘入库 |
| 体量 | **45 页**（`deck.yaml` 45 条；pptx 实测 45 张、备注 45 张） |
| 画布 | 960 × 540 pt（pptx 12192000 × 6858000 EMU） |
| 工程 | `decks\进入新时代-参赛版-v2\`（`deck.yaml` + `pages\*.yaml` + `_gen\kit3.py` + `build3a/b.py`） |
| 硬约束 | 内容右边界 ≤ 640 pt（右侧 1/3 讲师带，H1）；页眉三件套；节末整合 3 页 |
| 依据 | `corpus-teardown.md` §8 落地清单 + `参赛要求.md` H1–H7 |

**这一册新学到的 3 条**

1. **页眉三件套是「一次改动、全册受益」的最高 ROI 项。**
   `kit3.py` 的 `hd()` 里：`hd_sq [48,56,4,16]`、`hd_tag [60,52,300,22]`（14pt、环节色、粗）、`hd_core [404,52,236,22]`（14pt、`#3B4B57`、右对齐）、`hd_tt [48,78,592,40]`（28pt 粗、行高 1.25）、分隔线 `y=128`（1pt `#D3D7D6` + 64×2pt 环节色）。
   实测：`hd_core` 在 45 页里命中 40 页，缺的 5 页恰是封面 `p01`、深底环节页 `p06/p15/p23`、致谢 `p44`——**豁免集合必须写进验收清单，否则等同漏做**（v2 验收清单已补这一行）。

2. **编号即层级：投影缩小后仍可点名，卡片位置不行。**
   统一 `一、` → `1.` → `（1）` → `①`，同页最多两级；单条段落不加编号（防「满屏数字」）。
   反例：本册 5 处「第 1–6 块」用了 **12pt**（`p13_five`），低于 `deck.yaml` 声称的 `minFontSize: 14`——**声明值与产物必须互校**，这一条已被写进 `checklist.md` B 组。

3. **结构页比装饰页值钱：依据页 + 节末整合 + 答案分页，是「教学设计」的骨。**
   本册 `p03b_basis`（课标/素养/价值三栏）+ `p14b_integ`/`p22b_integ`/`p31b_integ`（三环节各自收口）+ `p31_answer`（问题页/答案页分离）。
   对比 v1（42 页、只有全课小结）：页数只多 3 页，但「环节结束有回扣、练习有答案页」是评委能指认的结构差异，不是审美差异。

## 4 维护纪律

- 只追加，不重写；旧结论被推翻时写「修订（YYYY-MM-DD）：原结论 X 不成立，证据 Y，新结论 Z」。
- 每条新学**必须带证据**：文件路径 + 行号，或一条可复跑命令的输出数字。无证据的感悟不进库。
- 三条上限：一册最多写 3 条，逼自己挑最有迁移价值的；其余写进该册工程的 `_notes`，不进库。
- 每次追完后更新 `page-patterns.md` / `number-bank.md` / `checklist.md` 里被影响的行——库是联动的，不是四份孤本。

## 5 册 002 · 库学习轮（480 份课件 + 27 套样式 + 3 份网络高星样本）

> 不是新做一册课件，而是把「库」当一册来学：先统计、再抽样、最后落规则。原始数据见 `_specs\_learn_corpus.md`、`_learn_styles.md`、`_learn_web.md`。

| 项 | 值 |
|---|---|
| 日期 | 2026-10-18 |
| 语料 | 480 份课件（17,375 页；1,118 张预览图） |
| 样式 | 27 套 morph-ppt 模板（4–7 页/套）+ 3 份 GitHub 高星中文模板（30/41/38 页） |
| 对照 | 本机 v2 参赛件（45 页 / 902 形状 / 20.0 形状每页） |
| 方法 | 脚本统计为主（4 个脚本），网页 6 次往返，未派子代理 |

**这一册新学到的 3 条**

1. **语料真相：36 页中位、79% 亮底——参赛要求的「35–50 页、亮底化」是主流而不是特例。**
   证据：`_learn_corpus.md` —— 480 份、17,375 页、页数中位 36（P25 25 / P75 45 / P90 55），35–50 页占 39%；预览图亮度中位 217/255，亮底 79%、深底 1%，纯白占比中位 62.8%。我们 45 页 + 亮底 + 大量留白，正落在主峰；反过来，深底方案要额外证明必要性。

2. **静态模板几乎不带动效：27 套样式全是 fade（8–12 处/套），3 份高星样本里 2 份零转场——动效是自写项，morph 是空白区。**
   证据：`_learn_styles.md` 27 行全部 `fade`；`_learn_web.md` 中 `data-viz-deck` fade×18、`report-massive-charts` 无、`red-teaching-framework` 无；本机 v1/v2 只有 fade + 6 页 slow（`add_transitions3.py` `SLOW={1,6,15,23,35,44}`）。结论：想让评委记住「会动的片子」，必须自己写 morph，且需要 PowerPoint 365/WPS 渲染（LibreOffice 看不到）。

3. **密度是隐藏旋钮：投影件 20 形状/页，高星图表件 58–78/页——照抄图表件密度会毁掉课堂可读性。**
   证据：`measure_density.py` —— v2 = 45 页 / 902 形状 / **20.0 形状每页**；`data-viz-deck` 58.5、`report-massive-charts` 59.2、`red-teaching-framework` 78.3。规则：投影场景上限 30 形状/页，超了拆页而不是缩字号。

## 6 册 003 · 版式学习轮（33 份 pptx / 379 页，真渲染 + 逐盒度量）

| 项 | 值 |
|---|---|
| 日期 | 2026-10-18 |
| 样本 | 27 套样式库（143 页）+ 3 份 GitHub 高星样本（109 页）+ 自制三册（127 页）= **379 页** |
| 方法 | `_probe/layout_metrics.py` 逐盒几何 + PowerPoint COM 导出 76 页 PNG + `_probe/build_atlas.py` 出图鉴 |
| 产物 | `layout-patterns.md`、`_layout_metrics.json`、`_layout_summary.md`、`atlas/layout-atlas.html`、`atlas/sheet-styles.jpg`、`atlas/sheet-web.jpg` |

**这一册新学到的 3 条**

1. **四栏卡片是主力版式（186/379 页），投影与阅读必须用两套阈值。**
   证据：`_layout_summary.md` 原型分布 = 多栏卡片 186、双栏 85、网格图表 49、单栏 33、大标题 26；四边距表里网络样本 58 元素/页、留白 62%、上边距 0.44 cm，而自制三册 20 元素/页、留白 64%、上边距 1.83 cm。规则：教室投影 ≤30 元素、正文 ≥16pt、上边距 ≥1.5 cm、留白 ≥60%；报告阅读才允许 40–60 元素、10–12pt。

2. **标题区有唯一安全线：x 5%–7%、y 14%–18%；字号比 1.8–2.5 比「越大越好看」可靠。**
   证据：`_layout_summary.md` 标题几何 —— 多栏卡片 x5.0%/y14.4%、双栏 x11.8%/y21.0%、网格图表 x2.0%/y2.6%（贴边反例）；字号比 自制 1.5 / 网络 2.0 / 样式库 2.5–4.5（editorial-story 20.0 → 正文 5pt，投影不可读）。我们 28pt 标题 + 16pt 正文是克制但正确的教学取舍。

3. **版式意图只在渲染图里看得见，XML 统计看不见——学习形式必须加"真渲染"。**
   证据：`_learn_styles.md` 里 27 套样式全部只带 fade、主题色全是 Office 默认色，从 XML 完全读不出版式风格；PowerPoint COM 导出 76 页（`_probe/export_slides.ps1`）后，才看清 14 套深底样式里 **11 套用"占画面 40%–60% 的大圆"作锚点**、封面共 **5 种结构**（左题右形 / 居中题+环绕 / 满版色块 / 深底大圆 / 实物场景）。结论：以后学版式先渲染再看，统计只用来定量。
