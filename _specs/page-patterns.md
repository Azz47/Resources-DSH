# 页型库（page patterns）

> 用途：下一册做同一类页时，直接抄坐标与字号，不再凭感觉摆。
> 数据来源：`decks\进入新时代-参赛版-v2\deck.yaml` + `_gen\kit3.py`（L12–L78、L195–L304）+ pptx 实测（45 页 / 902 个文字 run / 字号分布）。建立 2026-10-18。

## 0 基准与网格

| 项 | 值 | 说明 |
|---|---|---|
| 画布 | **960 × 540 pt** | 1px = 1pt；pptx 实测 12192000 × 6858000 EMU |
| 内容区 | **x ∈ [48, 640]**，`CW = 592` | 右侧 640–960 是讲师站位带，**硬约束 H1** |
| 正文起点 | `TOP = 142` | 页眉线 `y = 128` 之下留 14pt 气口 |
| 正文底线 | `BOT = 462` | 549 减去安全区 44 再留余量 |
| 安全区（deck.yaml 声明） | top 40 / bottom 44 / left 32 / right 48 | 与 kit 的 L=48 / R=640 不一致时**以 R=640 为准**（更严） |
| 右侧带 | 640–960，只放不承载信息的装饰 | 竖排单元名 + 页码 |

## 3 页型库

> 每型给「结构 + 关键坐标 + 实例页」。坐标省略页眉（统一见 §2）。

### P-01 封面（`p01_cover`）
- 结构：色块 + 标签(14) + 引题(16) + 主标(44, 两行) + 副标 + 底部信息
- 关键：主标宽度按 `CW` 收，**不越过 640**；右下角留 `AI 生成` 类水印位不用（v1 教训：AI 图带伪汉字，弃用）
- 禁忌：封面堆 5 行以上信息；主标超过 2 行

### P-02 单元导览（`p02_unit`）
- 结构：标题 + 竖排目录（章节名 + `02 / 45`）+ 一句单元主旨
- 关键：目录用 13–14pt，**不再出现第三种字号**

### P-03 四问框架（`p03_four`）
- 结构：标题 + 4 个等宽卡片（`card()`，宽 ≈ 140，间距 12–16）
- 关键：卡片高由 `nh()` 自适应，**不要手写死高**；4 卡等宽，左边界对齐 48

### P-04 依据页（`p03b_basis`）· 结构页
- 结构：三栏 = 课程内容 / 学科素养 / 核心价值；每栏「栏标 14pt 环节色 + 正文 16pt」
- 关键：三栏等宽（各 ≈ 190），中间留 12pt 缝；底部 `src_note` 引课标原文（含「2022 年版」字样）
- 为什么值钱：评委第一眼确认「素养导向、有依据」，缺这页整册像素材拼盘

### P-05 任务页（`p04_task`）
- 结构：标题 + 三张横条（`strip()`，高 ≈ 56–64）+ 编号 `01/02/03`（28pt 环节色）
- 关键：编号用 28pt，与标题同层级；三条任务**动词开头**

### P-06 情境页（`p05_ctx`）
- 结构：标题 + 一段引文（宋体 18–20）+ 出处 + 一张小图/图标
- 关键：引文行高 1.6，宽度 ≤ 520，右侧留空

### P-07 深底环节页（`p06_s1` / `p15_s2` / `p23_s3`）
- 结构：深底图 + 大编号（104pt，环节色或金）+ 页标题(30) + 一句导语 + 三条子目标
- 关键：`ophead()` 与 `hd_dark()` 二选一，**不要混用**（顶部坐标差 34pt）
- 禁忌：深底页放正文长段（对比度掉、投影发灰）

### P-08 要点页 2×2 / 并列（`p07_tech` / `p09_safe` / `p10_law` / `p11_culture`）
- 结构：2×2 卡片（`card()`，宽 ≈ 288，缝 16）或 1 图 + 3 卡
- 关键：卡片内「标题 18 + 正文 16」，**单卡 ≤ 3 行正文**；`card()` 的左色条 3pt 是统一识别符
- 禁忌：四张卡字数差 > 1 行（视觉失衡）；正文塞 4 行

### P-09 数据 / 图证页（`p08_traffic` / `p12_river`）
- 结构：标题 + KPI（38pt 数字 + 13pt 标签）+ 说明句（16pt）+ 图片来源（13pt）
- 关键：KPI 高度 = `22 + 46 + 4 + 标签高 + 14`（`kpi()`）；数字与标签**同一卡片内**，不跨列
- 强制：**每个数字必带来源行**（`src_note`，13pt，`#3B4B57`），口径写进 `number-bank.md`

### P-10 多块页（`p13_five` / `p17_five` / `p20_four`）
- 结构：标题 + 5–6 个横条块（`strip()`，高 ≈ 44–52，缝 8）
- 关键：块标签统一 14pt（本册误用 12pt，**已列为待修**）；块数 ≥ 5 时正文压到 16pt 单行
- 禁忌：块内换行导致高度不一致（用 `nh()` 算，别手填）

### P-11 取舍页（`p14_pick`）
- 结构：标题 + 两栏「保留 / 舍弃」+ 判断标准一行
- 关键：两栏顶对齐、行数对齐；判断标准单独用 `strip()` 高亮

### P-12 节末整合页（`p14b_integ` / `p22b_integ` / `p31b_integ`）· 结构页
- 结构：标题（「【重点整合】…」）+ 3–5 条收口（编号 `1. 2. 3.`）+ 一句回扣环节问题
- 关键：**每个环节结束必须有一页**，缺就补；条数与环节内要点数一致
- 为什么值钱：把散点收成 3–5 条，是「教学设计的收口」，不是总结页

### P-13 工具 / 脚手架页（`p18_tool` / `p21_scaffold`）
- 结构：标题 + 工具三件套（做什么/怎么用/注意）+ 一行示例
- 关键：脚手架要写**硬限制**（如「不超过 120 字；每条原因后必须跟一个事实；不许出现"很重要"」）

### P-14 范例 / 步骤 / 计划 / 汇报（`p22_demo` / `p26_steps` / `p27_plan` / `p28_report`）
- 结构：四类共用「标题 + 左步骤列（3–4 步，14pt 序号）+ 右示例卡（18pt 引文）」
- 关键：步骤编号与正文编号体系一致（`1.` 一级，不再套 `（1）`）

### P-15 练习页 / 答案页（`p36_q1`–`p38_q3` / `p31_answer` / `p42_key`）
- 结构：练习页 = 材料 + 问句（**只给题，不给答案**）；答案页 = 【答案】/【解析】+ 评分要点
- 关键：**问题页与答案页必须分开**；答案页标题就叫「答案与解析」；评分要点写「每小题 2 分，多选、错选不得分」这类可执行口径

### P-16 作业 / 量表 / 小结（`p32_hw` / `p33_rubric` / `p34_sum`）
- 结构：作业 = 分层三项（必做/选做/挑战）；量表 = 3–4 维 × 3 档；小结 = 「一句话 + 三条回扣」
- 关键：作业要写**交付形式与字数**（如「图文小报或 3 分钟短视频，须标注资料来源」）

### P-17 结束页（`p35_end` / `p44_thanks`）
- 结构：一句收束 + 单元回扣 + 致谢
- 关键：结束页不放新信息；深底/浅底与封面呼应

## 4 反模式（本册实测踩到的）

| # | 反模式 | 证据 | 改法 |
|---|---|---|---|
| 1 | 声明值与产物不一致 | `deck.yaml` 写 `minFontSize: 14`，pptx 实测 12pt × 5 | 每次导出后用 `checklist.md` B 组跑实测字号分布 |
| 2 | 孤页留在工程里 | `pages\` 48 个 yaml，`deck.yaml` 只列 45；孤儿 `p39_q4/p41_m2/p43_hw2` 页码还是 `x / 48` | deck.yaml 为准，孤页移 `_archive` 或补进清单 |
| 3 | 强调色当正文色 | `#B4552F` 14pt 在纸面 4.43:1（< 4.5） | 正文换 `#9E4525`（5.69:1）；或强调色只上 ≥18pt 粗体 |
| 4 | 页码分母不统一 | 45 页册里出现 `/48` | 页码由构建脚本统一注入，不手写 |
| 5 | 装饰侵占净空带 | 右侧 640–960 只允许「竖排单元名 + 页码 + 短横」 | 任何新装饰先过 H1 检查（右边界 ≤ 640） |
| 6 | 满页文字当专业感 | 样本是讲授型课件，评审要「一页一要点」 | 单页正文 ≤ 3 块、每块 ≤ 3 行 |
