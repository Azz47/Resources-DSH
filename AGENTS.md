# AGENTS

## Agent skills

### Issue tracker

GitHub Issues, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical state roles, default strings unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Wayfinder uses its own `wayfinder:*` labels. See `docs/agents/triage-labels.md`.

### Domain docs

single-context — one root `GLOSSARY.md` shared by the whole repo; architecture decisions live in `docs/adr/`. See `docs/agents/domain.md`.
